# rede-corporativa-packet-tracer
Rede corporativa simulada no Cisco Packet Tracer, com 4 VLANs, roteamento entre VLANs (router-on-a-stick), DHCP, DNS, intranet em HTTP, NAT/PAT para uma "internet" simulada e ACL bloqueando o RH do Financeiro. Inclui o arquivo .pkt, as configs e os prints dos testes.
